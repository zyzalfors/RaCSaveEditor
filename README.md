# Ratchet & Clank Series Save Editor
This GUI tool allows users to read and edit save files for the PlayStation 2 games Ratchet & Clank 1, 2, 3, Deadlocked/Gladiator. The tool supports reading and editing .bin raw save data, which can be extracted from various formats, such as .cbs, .max, .psv, .psu, .sbs, and .xps.

The tool can read and modify several game parameters:
- Ratchet & Clank: current level, bolts, completion times, ammo, skill points, and weapon/item unlocks
- Ratchet & Clank 2: current level, bolts, completion times, raritanium, nanotech, armor, crystals, moonstones, bolt multiplier, ammo, language, skill points, and weapon/item unlocks
- Ratchet & Clank 3: current level, bolts, completion times, nanotech, armor, crystals, bolt multiplier, ammo, language, skill points, and weapon/item unlocks
- Ratchet Gladiator/Deadlocked: current level, bolts, nanotech, Dread points, bolt multiplier, mods, ammo, language, skill points, and weapon/item unlocks

# Ratchet & Clank Series Save Editor
This GUI tool allows users to read and edit save files for the PlayStation 2 games Ratchet & Clank 1, 2, 3, Deadlocked/Gladiator. The tool supports reading and editing .bin raw save data, which can be extracted from various formats, such as .cbs, .max, .psv, .psu, .sbs, and .xps.

The tool enables modification of various properties, such as the amount of bolts, nanotech, weapons/items, ammo, skill points, and other collectibles like crystals and raritanium.
